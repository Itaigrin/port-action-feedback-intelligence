What this changes compared with a flat-theme dashboard

Flat theme only
  • “Backend & invocation” becomes a catch-all.
  • Completed records can look like current demand.
  • General automation feedback can inflate Action Configuration insights.
  • Charts show a count, but not the root cause.
Evidence-first multidimensional model
  • Feature area and problem type are separate.
  • Lifecycle status is explicit in every priority decision.
  • Out-of-scope feedback remains auditable but excluded.
  • Every insight can reveal the supporting source records.
